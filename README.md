# odin-landing-page

Project Description: This project is a basic landing page design. 
The colors and styles of most sections was given, while positioning and sizes were done manually to practice using flexbox.
The page consists of 4 sections: hero, information, quote, call to action, as well as a header and footer.

Skills: With the current version of this project, I was able to practice flexbox techniques to more easily place content on a webpage.
I also was able to practice matching a given webpage design mostly from scratch.
